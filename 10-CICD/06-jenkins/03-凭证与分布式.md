# 3. 凭证管理与分布式构建（概念）

## 凭证管理

- 账号、Token、SSH Key **不进仓库明文**  
- 存在 Jenkins Credentials，Job 运行时注入  
- 对应 GitLab：**CI/CD Variables**（masked / protected）  

面试只说：

> 「两边都是集中管凭证、运行时注入；轮换与权限控制同样重要。」

## 分布式构建

- 多 Agent 分担负载  
- 用 **标签** 把 Job 派到特定机器（GPU、Windows、交叉编译机）  
- 对应 GitLab：Runner tags / 私有 Runner  

## 和主力 GitLab 的关系（话术）

> 「我主力 GitLab CI。Jenkins 若在老项目里出现，我会按 Master/Agent、Jenkinsfile、凭证与节点标签这几块快速对齐，排查思路和 GitLab 五步法相通。」
