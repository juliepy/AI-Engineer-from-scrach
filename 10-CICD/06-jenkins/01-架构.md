# 1. Jenkins 架构：Master + Agent

| 角色 | 职责 | 对应 GitLab |
|------|------|-------------|
| **Master（Controller）** | 调度、UI、任务定义、汇总结果 | GitLab 协调端 |
| **Agent（节点）** | 真正执行构建 | GitLab Runner |

```
开发者提交 / 触发
  → Master 接到任务
  → 分配到空闲 Agent
  → Agent 跑流水线步骤
  → 结果回 Master
```

要点：

- 分布式：重活放 Agent，Master 别既当调度又扛全部编译  
- Agent 可按标签分流（Linux / Windows / 嵌入式工具链机）  

口述：

> 「Jenkins 是 Master 调度、Agent 执行；和 GitLab 的 Server + Runner 是同一类分工。」
