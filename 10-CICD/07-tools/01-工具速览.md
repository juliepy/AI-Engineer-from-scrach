# 1. 工具速览

| 类别 | 工具 | 用途 | 面试一句 |
|------|------|------|----------|
| 测试框架 | **pytest** | 单测 / 门禁用例执行与标记分流 | 「用目录 + `-m` 区分 MR/Gate1/Daily/发版 case」 |
| 代码扫描 | **SonarQube** | 静态分析 / 质量门禁 | 「扫缺陷与坏味道，可设质量阈卡住合并」 |
| 制品仓库 | **Nexus** | 程序包、固件、安装包 | 「CI 产出上传 Nexus，版本可追溯」 |
| 容器 | **Docker** | 封装构建环境、编译工具链 | 「Runner 用镜像跑 Job，环境统一不脏机器」 |

## 别混

| 混淆 | 纠正 |
|------|------|
| Sonar = 单测 | Sonar 偏静态分析；单测是 pytest 等 |
| Nexus = Git 仓库 | Nexus 存制品；Git 存源码 |
| Docker = 一定上生产 K8s | CI 里首先是构建环境封装 |
