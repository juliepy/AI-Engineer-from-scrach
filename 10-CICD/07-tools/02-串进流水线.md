# 2. 四工具串进流水线

```
MR / push / tag / schedule
  → GitLab 调度 + Runner（Docker 镜像环境）
  → Lint
  → SonarQube 扫描（质量门禁）
  → pytest（按门禁选 case）
  → 编译构建（镜像内工具链）
  → 上传 Nexus（SHA / tag 版本）
  → artifacts 归档报告
```

口述（40 秒）：

> 「Runner 用 Docker 提供干净环境；Sonar 做静态质量门禁；pytest 按门禁跑不同用例；构建产物按 SHA 进 Nexus；报告走 artifacts。四个工具分别覆盖环境、扫描、测试、制品。」
