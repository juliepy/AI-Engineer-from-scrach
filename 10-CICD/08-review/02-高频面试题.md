# 2. 高频面试题（速刷）

> 先闭卷写关键词，再对要点。

---

**Q1. CI / 持续交付 / 持续部署区别？企业一般做到哪？**

要点：集成测得住；交付随时上但需人确认；部署全自动。多数到持续交付。

**Q2. Pipeline、Stage、Job、Step、Runner 关系？**

要点：从大到小；Runner 执行 Job。

**Q3. Cache 和 Artifacts 区别？**

要点：加速 vs 留产物；依赖缓存 vs 包/报告。

**Q4. 为什么 MR / Gate1 / Daily / 发版 case 不同？**

要点：触发时机 + 覆盖面/耗时；目录与 `-m` 分流。

**Q5. Docker 执行器优势？**

要点：干净统一、封装工具链、不污染宿主机。

**Q6. 流水线挂了怎么查？**

要点：触发 → Runner → 脚本 → 外部服务 → 凭证。

**Q7. 构建太慢怎么优化？**

要点：cache、并行、增量；快慢门禁分流；超时/重试。

**Q8. 制品为何不用 latest？**

要点：不可追溯、会覆盖、难回滚审计。

**Q9. 会 Jenkins 吗？**

要点：主力 GitLab；Master/Agent + Jenkinsfile 理念互通，可快速上手。

**Q10. DevOps 等于 CI/CD 吗？**

要点：不等于；CI/CD 是落地实践之一。
