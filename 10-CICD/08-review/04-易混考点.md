# 4. 极易混淆考点（大纲附录）

## Cache vs Artifacts

| | Cache | Artifacts |
|---|--------|-----------|
| **目的** | 加速本次 / 后续流水线 | 保存输出产物 |
| **典型内容** | 依赖、编译中间文件 | 程序包、测试报告 |
| **用途** | 临时缓存，提升速度 | 可下载，供后续 Job 使用 |

## Docker 执行器优势

- 干净、统一的构建环境  
- 方便封装各类编译工具链  
- 不污染宿主机  

## 再加两条易混

| 易混 | 记住 |
|------|------|
| Delivery vs Deployment | 交付要人点；部署全自动 |
| 多门禁 = 同一批 case 换时间 | 否；触发不同，**用例集也不同** |
