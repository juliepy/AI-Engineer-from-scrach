# 3. 经历话术终稿

在 [05-troubleshoot/03-经历包装.md](../05-troubleshoot/03-经历包装.md) 草稿上，压成 **90 秒** 终稿。

## 结构（严格计时）

| 时间 | 内容 |
|------|------|
| 0~15s | 背景：哪条门禁、什么现象 |
| 15~60s | 动作：按排查五步，你具体做了哪 2~3 刀 |
| 60~90s | 结果：恢复/加速/避免关禁；沉淀了什么 |

## 终稿填写区

```
【背景】


【动作】


【结果】


【可追问细节】（日志关键词 / 改了哪段 rules / 时长数据）

```

## 搭配金句（选一句收尾）

- 「优化可以分流和加速，但不把关禁当开关乱关。」  
- 「配置和业务代码同仓评审，保证流水线变更可审计。」  
- 「制品绑定 SHA，出了问题能回到精确提交。」
